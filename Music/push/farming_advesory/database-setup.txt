# Database Setup Instructions

## 1. Create Database
Open MySQL command line or MySQL Workbench and run:
CREATE DATABASE smart_farming_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

## 2. Update Application Properties
Edit src/main/resources/application.properties:
spring.datasource.url=jdbc:mysql://localhost:3306/smart_farming_db
spring.datasource.username=your_mysql_username
spring.datasource.password=your_mysql_password

## 3. Run Application
mvn spring-boot:run

The application will auto-create all tables based on entities.
